A modular toolkit for WooCommerce stores with product-page enhancements, checkout shortcuts, and shopping experience features.

== Description ==

Conversion Suite for WooCommerce provides a collection of optional modules designed to enhance the shopping experience in WooCommerce stores.

Store administrators can enable or disable individual modules from the plugin dashboard.

Available modules:

Buy Now - Direct checkout from product pages.

Exit Intent - Configurable exit-intent popup.

Free Shipping Progress - Progress indicator toward a free shipping threshold.

Frequently Bought Together - Manually selected complementary products.

Low Stock - Stock-based alerts on product pages.

One Click Order - Quick WooCommerce order requests.

Quick Checkout - Simplified classic WooCommerce checkout form.

Recently Viewed - Recently viewed products.

Sale Countdown - Countdown for scheduled WooCommerce sales.

Sticky Add to Cart - Floating purchase bar on product pages.

Trust Badges - Configurable trust messages near Add to Cart.

WhatsApp Order - Product inquiries through WhatsApp.

Features depend on the selected modules and their configuration.

== Installation ==

Install and activate WooCommerce.

Upload the Conversion Suite for WooCommerce plugin through Plugins > Add New > Upload Plugin.

Activate Conversion Suite for WooCommerce.

Open the plugin dashboard in WordPress administration.

Enable and configure the modules you want to use.

== Frequently Asked Questions ==

= Is WooCommerce required? =

Yes. WooCommerce must be installed and active.

= Can I disable individual modules? =

Yes. Modules can be enabled or disabled independently.

= Does Quick Checkout support WooCommerce Checkout Blocks? =

Quick Checkout is designed for the classic WooCommerce checkout form.
